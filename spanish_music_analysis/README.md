# Spanish Music Chart Analysis 🎵

## Overview

An end-to-end data analysis project exploring trends and performance
patterns in Spanish music charts.

The project analyzes 27,000+ chart records using Python and Pandas,
with an interactive Streamlit dashboard for visualization.

## Objectives

- Clean and normalize song and artist data
- Identify first chart appearances
- Analyze peak chart performance
- Calculate time-to-peak
- Analyze song lifecycle and churn
- Visualize music chart trends

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Jupyter Notebook

## Analysis

The project includes analysis of:

- Song and artist performance
- First appearance dates
- Peak chart positions
- Time-to-peak
- Song lifecycle
- Churn and retention
- Chart trends over time

## Interactive Dashboard

An interactive Streamlit dashboard was developed to explore
the analyzed music chart data.
